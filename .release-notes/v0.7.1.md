# v0.7.1 リリースノート

> 📅 リリース日: 2026-06-21

## ハイライト

呼び出しモードが Whisper+要約（かつオンデバイスWhisper有効時）で文字起こしに掛かった時間のみを PreviewScreen に表示するようになりました。マルチモーダルや旧データは従来表示にフォールバックします。

## 変更内容

### 追加機能

- **文字起こし専用経過時間表示**
  - DBスキーマ v3→v4: `transcribeDurationMs` / `llmCallMode` カラム追加
  - MIGRATION_3_4: 既存セッションは DEFAULT 値で後方互換
  - `Session` モデル: 2 フィールド追加、`LlmCallMode` は防御的パース
  - `ProcessingViewModel`: `transcribeStartMs` 計測 + Session 保存
  - `PreviewScreen`: `llmCallMode` 判定で transcribe 時間優先表示
  - マルチモーダル / 旧データは既存表示にフォールバック
