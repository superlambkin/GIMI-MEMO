# v0.9.1 リリースノート

> 📅 リリース日: 2026-08-22

## ハイライト

文字起こし方式を 3 値化（クラウド / ローカルスマホ / ローカルPC）し、設定・録音・インポート確認画面で選択可能に。ローカル PC Whisper サーバ（POST `/asr` multipart）クライアントを追加し、25MB 制限なしで分割せず送信できるようになりました。

## 変更内容

### 追加機能

- **文字起こし方式の 3 値化**
  - クラウド / ローカルスマホ / ローカルPC の 3 方式から選択可能
  - 設定画面・録音画面・インポート確認画面で切替 UI を提供
- **ローカル PC Whisper サーバ対応**
  - POST `/asr` multipart クライアント追加
  - 25MB 制限なしで分割せず送信
  - 既定 URL: `http://192.168.0.88:9000/asr`
- **接続テスト機能**
  - 設定画面に接続テストボタン追加
  - テスト成功時のみ URL を保存
- **平文 HTTP 許可**
  - `usesCleartextTraffic` でローカルサーバ・Ollama 用途を許可
- **文字起こし結果表示の拡張**
  - 音声時間・分割・変換時間の内訳表示

### バグ修正・改善

- **メール添付の原文 TXT が MIME 不一致で破棄される問題を修正**
  - `attachmentMime */*` で解決
- **Word 出力からアスタリスク（`**`）を除去**

- Android 8.0 (API 26) 以上

- JDK 21（ビルド時）
