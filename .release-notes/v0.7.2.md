# v0.7.2 リリースノート

> 📅 リリース日: 2026-06-21

## ハイライト

Whisper モデルを FP16 から GGUF Q4_0 base（約 42MB）に刷新し、APK サイズを大幅削減。同梱モデル変更に加えて VAD 有効化・30 秒窓 + 2 秒オーバーラップ転写・録音画面 UI 改善を同時に提供します。

## 変更内容

### 追加機能

- **Whisper モデル刷新（FP16 → GGUF Q4_0）**
  - 同梱モデルを `q4_0.gguf` (約 42MB) に刷新（FP16 141MB → Q4 42MB）
  - 旧 FP16（`ggml-base.bin`）は download 経路扱いに降格 + `cleanupLegacyModel` 対象に
  - `OnDeviceWhisperClient` のデフォルト `modelName` を `q4_0.gguf` に更新
  - `noCompress` に `"gguf"` 拡張子追加
- **VAD 有効化**
  - whisper.cpp 内蔵 VAD（`vad_model_path=NULL`）
- **30 秒窓 + 2 秒オーバーラップ転写**
  - JNI に `fullTranscribeChunked(offset_ms, duration_ms)` 追加
  - `WhisperModelImpl` に `transcribeWithOverlap` / `transcribeFileWithOverlap` 追加
- **録音画面 UI 改善**
  - サンプリングレート / ビットレートを上部表示
  - `RecordingViewModel` に `recordingConfig` StateFlow 追加

### バグ修正・改善

- CPU コア数 - 1 でスレッド計算（`coerceAtLeast(1)`）
- OpenCL/GPU フラグ `use_gpu` パラメータを JNI `initContext` / `WhisperModel.load` / `OnDeviceWhisperClient` コンストラクタに追加
