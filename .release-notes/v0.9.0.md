# v0.9.0 リリースノート

> 📅 リリース日: 2026-08-21

## ハイライト

長尺音声のチャンク文字起こし改善（ストリーミング分割・指数バックオフリトライ・部分失敗警告）と、複数 MP3 一括文字起こし + 時系列結合を実現。さらに他アプリからの音声共有受け取り（ACTION_SEND）と DeepSeek V4 Flash 対応を追加しました。

## 変更内容

### 追加機能

- **長尺音声のチャンク文字起こし改善**
  - ストリーミング分割
  - 指数バックオフリトライ
  - 部分失敗警告
- **複数 MP3 一括文字起こし + 時系列結合**
  - 個別セッション + 結合セッション両対応
- **共有受け取り**
  - 他アプリからの音声共有受け取り（ACTION_SEND）
- **LLM プロバイダ対応**
  - DeepSeek V4 Flash 対応（既定 + 選択肢）
- **UI 改善**
  - 予測時間・進捗表示の精度改善
  - 文字数表示

### バグ修正・改善

- 再試行時の API キー未反映バグ修正
- メインスレッドフリーズ修正
- WAV デコード OOM 修正
- メール添付の原文 TXT 未添付バグ修正
