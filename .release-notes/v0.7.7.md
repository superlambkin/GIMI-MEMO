# v0.7.7 リリースノート

> 📅 リリース日: 2026-06-23

## ハイライト

録音画面にサンプリングレート / ビットレートの常時表示、波形ビジュアライザの録音中限定表示など、UI 改善を実施。並行してストリーミング文字起こし基盤（WIP: Work In Progress）の実装を進めました。

## 変更内容

### 追加機能

- **UI 改善**
  - 録音開始画面にサンプリングレート / ビットレートを Idle 状態で表示
  - 波形ビジュアライザを録音中のみ表示（StoppedPlayback で非表示）
  - 上部の重複 LocalWhisper トグルを削除
  - StoppedPlayback に [戻る] ボタンを追加、キャンセルと横並び
  - 未使用変数 `useOnDeviceAsr` を削除
- **ストリーミング文字起こし基盤（WIP）**
  - `AudioRecorder` に `pcmChunkFlow`（`SharedFlow<ShortArray>`）追加
  - `MediaRecorderLameImpl` に `AudioRecord` で PCM 並走取得、`startPcmStream()`
  - `TranscriptDelta` ストリーム結果データクラス（新規）
  - `LlmClient.transcribeStream()` インターフェース追加
  - `OnDeviceWhisperClient` に 3 秒窓 + 0.5 秒オーバーラップの `transcribeStream()`
  - `WhisperModel.transcribeChunk()` + `WhisperSegment` 追加
  - `WhisperModelImpl` に `chunkMutex` 直列化 + JNI 呼び出し
  - `WhisperJni` に `getSegmentTimestamp0/1`, `fullTranscribeChunked`
  - `whisper_jni.c` ネイティブ側 chunk 文字起こし + centiseconds→ms 変換
  - `RecordingViewModel` に `partialTranscript` StateFlow、`streamingJob` 制御
  - `RecordingScreen` に `PartialTranscriptView` UI（仮）
- **ビルド設定**
  - `gradle.properties` に `org.gradle.java.home` を JDK 21 に固定
