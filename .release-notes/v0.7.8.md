# v0.7.8 リリースノート

> 📅 リリース日: 2026-06-23

## ハイライト

ストリーミング文字起こし計画を中止し、コードをクリーンアップ。端末内モデル（medium/tiny）では処理速度不足、クラウド API streaming はレイテンシ・コストの観点から不採用となったため、録音中リアルタイムプレビューは見送られました。

## 変更内容

### 追加機能

- なし

### バグ修正・改善

- **ストリーミング文字起こし計画中止・コードクリーンアップ**
  - `OnDeviceWhisperClient.transcribeStream` 実装（`emptyFlow` 継承）を削除
  - `RecordingViewModel` から `partialTranscript`, `streamingJob`, `TranscriptionService` 連携を削除
  - `RecordingScreen` から `PartialTranscriptView`, Idle 状態の LocalWhisperToggle を削除
  - 不要インポート・定数・ヘルパーメソッドを削除
- **残存**
  - `StoppedPlaybackAndTranscribe` 内の LocalWhisperToggle（録音停止後の切替用）は維持
  - PCM ストリーム基盤（`AudioRecorder.pcmChunkFlow`）は将来再用可能なまま維持
  - 録音設定表示（SR/BR）は Idle 画面に継続表示
