## 技術的決定事項

| 項目 | 決定 | 理由 |
|---|---|---|
| Whisper 量子化 | GGUF Q4 → Q5_1 に変更 | Q4 で一部端末ロード失敗、Q5_1 で安定 |
| 文字起こし時間表示 | PreviewScreen に別軸追加 | ユーザー待機不安の解消 |
| 録音音量 | ゲイン調整で音量アップ | 同梱アプリと比較した体感音量改善 |
| 要約プロンプト | 録音日時を埋め込み | LLM の時系列把握精度向上 |
| TXT 再要約 | SessionDetail 画面で LLM 再呼び出し | テンプレート変更後の再生成 UX |
| ストリーミング転写 | **中止** (v0.7.8) | 端末内モデル処理速度不足 + クラウドAPIはコスト/レイテンシ課題 |
| 表示モード | ダーク/ライト/システム切替 | 端末設定に追従する選択肢 |
