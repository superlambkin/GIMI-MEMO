## 時系列ログ

### Day 1 (2026-06-14 朝〜昼) — バグ修正ラッシュ

- **Bug 報告 #1**: 録音画面遷移後、再生/文字起こし画面に前進できない
  - 原因: `LaunchedEffect(System.currentTimeMillis())` のキーが毎回変わり、`resetLastSavedSession()` が再実行され続けていた
  - 修正: `LaunchedEffect(Unit)` に変更、reset は `LaunchedEffect(state)` 側に分離
  - コミット: 同サイクルで即適用
- **Bug 報告 #2**: 録音後タイマーが 00:00 で固定
  - 原因: 停止時の elapsedMs リセット
  - 修正: `lastSavedSession.durationMs` を表示
- **Bug 報告 #3**: メール共有でメーラーは開くが宛先/添付なし
  - 原因: `setSelector(ACTION_SENDTO + mailto:)` が Gmail/MIUI で EXTRA_EMAIL を破棄
  - 修正: setSelector 撤廃、ClipData grant 補強、Gmail 直起動 fallback
  - 経緯: 1 度目 (`setSelector` 撤廃) → 2 度目 (ChatGPT Gmail 衝突) → **最終**: setSelector + 宛先強制
- **要件**: MP3 インポート後すぐに文字起こしに進む → 再生確認画面 (ImportReviewScreen) を挟む

### Day 1 午後 — base モデルと小型化の判断

- 質問: 「文字起こしに時間がかかりすぎる。短縮できないか?」
  - 提案: tiny モデル (75 MB) に切替

#### 発見した MultiAgent 上の問題

1. **Agent 間コンテキスト共有不可**: 子 Agent は別セッションで動くため、自分の Agent ID の記憶が引き継がれない

3. **WebSearch 制限**: 検索 API が一時的に "400 invalid params" を返した

## 技術的決定事項

| 項目 | 決定 | 理由 |
|---|---|---|
| API Key 暗号化 | `EncryptedSharedPreferences` 継続採用 | 既存実装継承 |
| 自動選択の優先順位 | OpenAI → ClaudeProxy → Ollama → DeepSeek → MiniMax | multimodal > ローカル > クラウドテキスト |
| OnDevice Whisper 自動判定 | `!providerConfig.supportsMultimodal` | multimodal 対応ならクラウドで音声処理 |
| Think タグ除去 | LLMEvent.Complete 時に `stripThinkTags` | ストリーミング中は逐次処理が重いため最終結果のみ |
| メール共有 MIME | `message/rfc822` + ClipData grant | 旧 `application/octet-stream` は Gmail で添付扱われず |
| Room DB バージョン | v1 → v2 (processingDurationMs 追加) | `fallbackToDestructiveMigration` で破壊的移行を許容 |
