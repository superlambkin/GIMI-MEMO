## 1. GijiMemoってなに？

GijiMemo（ギジメモ）は、**お話ししたことを自動で文字にしておぼえてくれる** アプリです。

🎤 会議（かいぎ）や授業（じゅぎょう）で話したことを：
1. **録音（ろくおん）** する
2. **AI（じんこうちのう）** が文字におこす
3. **まとめて** Word やメールにする

---

## 2. 最初にやること

アプリをインストールしたら、**かならず最初にやること** があります。

### 🔑 APIキーを入力しよう

APIキー（あいぴーあい きー）は、アプリが AI をつかうためのパスワードです。

1. ホーム画面の ⚙（はいたつのマーク）をタップ
2. 「**API Key を一括管理**」をタップ
3. **OpenAI** のうえに APIキーを入力
4. 右上の ✓（チェック）をタップして保存

> 💡 APIキーはおうちの人に聞いてね！

## 4. 録音する（ろくおん）

マイクを使って新しい録音を始めるときの画面です。

```
┌─────────────────────────────────┐
│      🔴 録音中                  │
│                                 │
│         ●●●●●●                  │
│       ● 波形 ●                  │
│      ●  00:15  ●                │
│       ●  ●●●  ●                 │
│         ●●●●                    │
│                                 │
│     [⏸ 一時停止]  [■ 停止]     │
│                                 │
└─────────────────────────────────┘
```

### つかいかた

1. **🔴 録音** ボタンを押す → 録音が始まる
2. 話したいことを話す
3. **■ 停止**（ていし）ボタンで録音をやめる
4. 自動で保存（ほぞん）される

### ボタンの説明

| ボタン | なまえ | 説明 |
|-------|--------|------|
| 🔴 録音開始 | ろくおんかいし | 録音を始める |
| ⏸ 一時停止 | いちじていし | ちょっとだけ止める |
| ▶ 再開 | さいかい | 一時停止から戻す |
| ■ 停止 | ていし | 録音を終わって保存する |

> ⚠️ 上のまるいグラフ（声紋、せいもん）は、声の大きさをあらわしています。大きい声だとビームが長くなります。

## 5. 音声ファイルを入れる（インポート）

パソコンやスマホに保存してある音声ファイルをアプリに入れる画面です。

1. ホーム画面の「**ファイルを選ぶ**」をタップ
2. スマホの中から音声ファイル（.mp3 や .m4a）を選ぶ
3. しばらくまつと「**インポート完了**」と表示される

```
┌─────────────────────────────────┐
│   🎵 インポート完了              │
│                                 │
│        36:38                    │
│                                 │
│ 音声を再生して内容を確認しよう！  │
│                                 │
│     [▶ 再生]  [■ 停止]         │
│   ████████░░░░░░░░ 15:20/36:38 │
│                                 │
│    [🇯🇵 日本語]  [🇨🇳 中国語]   │
│                                 │
│         [キャンセル]             │
└─────────────────────────────────┘
```

### ボタンの説明

| ボタン | 説明 |
|-------|------|
| ▶ 再生 | 音声をきく |
| ⏸ 一時停止 | 音声をちょっと止める |
| ⏹ 停止 | 音声を止める |
| ██ シークバー | ドラッグすると早送り・巻き戻しできる |
| 🇯🇵 日本語 | 日本語で文字起こしする |
| 🇨🇳 中国語 | 中国語で文字起こしする |
| キャンセル | やめる（ファイルも消える） |

## 6. 文字起こし（もじおこし）

音声を自動で文字にする処理中の画面です。

```
┌─────────────────────────────────┐
│        文字起こし                │
│                                 │
│    ┌──────────────┐             │
│    │  ●●  ●●     │             │
│    │ ●   1/2   ● │             │
│    │  ●  ●●●  ●  │ <- 円グラフ │
│    │   ● ●   ●   │             │
│    │    ●●●●     │             │
│    └──────────────┘             │
│ ■分割 45秒 ■Ch1 ■Ch2          │
│ チャンク 1/2 | 予想残り 1:30   │
│ 全体予測: 3:15                  │
│ ████████░░░░░░░░░░░░░          │
│ 経過時間: 1分23秒               │
│ M4A 分割中...                   │
│ 使用中: OpenAI / whisper-1      │
└─────────────────────────────────┘
```

### 画面の見方

| もの | 説明 |
|------|------|
| 🥧 **円グラフ** | 青＝分割時間、オレンジ＝API時間 |
| **1/2** | チャンクの進みぐあい（2個中1個目） |
| **予想残り** | あとどのくらいかかるかの予想 |
| **全体予測** | 全部でどのくらいかかるかの予想 |
| **使用中** | 今どのAIをつかっているか |

### 処理のながれ

```
① 準備中 → ② M4A分割中 → ③ チャンク1送信中 → ④ チャンク2送信中 → ⑤ 文字起こし完了
```

> 💡 画面が暗くならないようになっています。しばらく待っていてね！

## 7. 要約（ようやく）

文字起こしが終わったら、**要約（ようやく）＝まとめ** を作ります。

### 文字起こし確認画面

```
┌─────────────────────────────────┐
│ 文字起こし結果      処理時間:3:12│
│                                 │
│ ┌───────────────────────────┐  │
│ │ ここに文字起こしされた文章が │  │
│ │ 表示されます。              │  │
│ │ 編集（へんしゅう）もできます │  │
│ └───────────────────────────┘  │
│                                 │
│ [▶ 再生] [⏹ 停止]              │
│ ████████░░░ 03:15/38:20        │
│                                 │
│ [リトライ]  [戻る]              │
│ [保存(TXT)] [要約]              │
└─────────────────────────────────┘
```

### 要約の種類をえらぶ

「要約」を押すと、まとめかたをえらべます：

```
┌─ 要約設定 ──────────────────┐
│ 原文文字数: 12,244 文字      │
│                              │
│ 種類: [議事録 ▼]             │
│       ┌──────────┐          │
│       │ 議事録     │ ← 会議用│
│       │ 講演会     │ ← 講演 │
│       │ 授業       │ ← 授業 │
│       │ 取材       │ ← 取材 │
│       │ 雑談       │ ← お話 │
│       │ DR         │ ← 設計 │
│       └──────────┘          │
│                              │
│  最大文字数: 1200 ✨         │
│  [100──────●──────50000]    │
│                              │
│      [キャンセル]  [ OK ]    │
└──────────────────────────────┘
```

### 種類（しゅるい）の説明

| 種類 | どんなときに使う？ | できるもの |
|------|------------------|-----------|
| 📝 議事録 | 会議（かいぎ） | 決定事項やアクションがわかる |
| 🎤 講演会 | こうえん・セミナー | 話のポイントがわかる |
| 📚 授業 | じゅぎょう・教室 | 板書や質問がまとまる |
| 🎙 取材 | インタビュー | Q&A形式で整理される |
| 💬 雑談 | なんでもおしゃべり | 話題ごとにまとまる |
| 🔍 DR | デザインレビュー | 課題や対策が整理される |

> 💡 文字数の数字（1200など）はスライダーで変えられます！

## 8. 結果を見る（けっかをみる）

要約ができると、きれいにまとまった文章が見られます。

```
┌─────────────────────────────────┐
│  要約結果          1,245 文字   │
│  [縮小][拡大]              [▶再生]│ ← 読み上げ
│                                 │
│  講演会概要                     │
│  タイトル: 給食が変える学校      │
│  講師: 現役校長（3校目）        │
│                                 │
│  講演内容                       │
│  開会の挨拶と導入               │
│  講師は校長がこのような場に...  │
│                                 │
│  決定事項                       │
│  （特になし）                   │
│                                 │
│  感想・考察                     │
│  本講演は...                    │
│                                 │
│  受信者: [メールアドレス▼]      │
│                                 │
│  [    メールで共有    ]         │
│  [文字起こし結果] [メニューへ戻る] │
└─────────────────────────────────┘
```

### できること

| ボタン | 説明 |
|-------|------|
| 🔍 縮小/拡大 | 文字の大きさを変えられる |
| ▶ 再生/■停止 | 文章を読み上げてもらう |
| 📋 COPY | 文章をコピーする |
| ✉️ メールで共有 | メールで送る |
| 📄 文字起こし結果 | 元の文字起こしを見る |
| 🏠 メニューへ戻る | ホーム画面に戻る |

## 9. メールで送る

要約した結果をメールでおくることができます。

### 送られるファイル

| ファイル | 中身 |
|---------|------|
| 📄 **Word（ワード）** | きれいにまとまった要約（見出し付き） |
| 📝 **Markdown** | インターネット用の形式 |
| 📃 **TXT（テキスト）**  | 文字起こしの全文 |

メール本文には **要約の最初の500文字** と **ファイルの説明** が入ります。

## 🎯 まとめ

### ぜんぶのながれ

```
録音/インポート
    ↓
文字起こし（30秒〜5分ぐらい待つ）
    ↓
文字起こし確認（編集できる）
    ↓
要約（種類を選ぶ）
    ↓
結果を見る（読む・印刷・メール）
```

### こまったときは

| こまったこと | かいけつ方法 |
|------------|------------|
| 文字起こしが始まらない | APIキーが入っているか確認 |
| エラーが出た | 「リトライ」ボタンを押す |
| 画面が白い | アプリを起動しなおす |
| 文字が小さい | 画面の「拡大」ボタンを押す |
