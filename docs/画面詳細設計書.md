# GijiMemo 画面詳細設計書

> 各画面の機能、ボタン、入力項目を詳細に記載する。

---

## 1. HomeScreen（ホーム画面）

### 概要
アプリ起動時のトップ画面。録音開始、ファイルインポート、過去セッション一覧を表示。

### UI要素

| 要素 | 種類 | 説明 |
|------|------|------|
| TopAppBar | ヘッダー | 「GIMI MEMO v0.7.8」表示、右に設定アイコン |
| セッションリスト | LazyColumn | 過去の録音セッションが時系列で表示される |
| FAB（録音） | ボタン | 画面右下の「🔴」ボタン、タップで録音画面へ遷移 |
| ファイル選択 | ボタン | 「ファイルを選ぶ」、ActivityResultContracts.OpenDocument で音声ファイル選択 |
| 設定ボタン | アイコン | ⚙ 設定画面へ遷移 |

### セッションカード項目

| 項目 | 表示内容 |
|------|---------|
| タイトル | セッション名（初期は自動生成） |
| 日時 | 作成日時 |
| ステータス | 完了 / 文字起こし中 / 失敗 など |
| モデル | 使用したLLMプロバイダ・モデル |

## 2. RecordingScreen（録音画面）

### 概要
マイク録音を行う画面。波形可視化、再生制御、停止後の操作を提供。

### 状態遷移

```
Idle → Recording → Paused → Recording → Idle (Stopped)
```

### 各状態のUI

#### Idle（待機中）- 新規録音可能状態

| 要素 | 説明 |
|------|------|
| タイトル | 「未開始」 |
| 設定表示 | サンプリングレート/ビットレート（例: 16kHz · 128kbps） |
| 時間表示 | "00:00" |
| 録音開始ボタン | 🔴 「録音開始」（v0.7.7: 波形ビジュアライザは非表示） |

#### StoppedPlayback（Idle + 録音保存済み）

| 要素 | 説明 |
|------|------|
| タイトル | 「未開始」 |
| 時間表示 | 録音時間（例: "30:10"） |
| 再生コントロール | 「録音を再生」/ 一時停止・停止 |
| シークバー | 再生位置スライダー + 経過時間表示 |
| ローカルWhisper切替 | ON/OFF ラジオボタン（StoppedPlaybackAndTranscribe内） |
| 言語選択 | 「日本語」「中国語」ボタン（文字起こしトリガー） |
| 保存ボタン | 「保存（音声ファイル）」 |
| 戻るボタン | ホーム画面へ戻る（録音保持） |
| キャンセルボタン | 録音を破棄して新規録音に戻る |

#### Recording（録音中）

| 要素 | 説明 |
|------|------|
| 波形ビジュアライザ | Canvas 円形、72本のビームで振幅表示（録音中のみ表示） |
| 経過時間 | 録音開始からの経過時間（秒） |
| 一時停止ボタン | ⏸ |
| 停止ボタン | ■ |

#### Paused（一時停止中）

| 要素 | 説明 |
|------|------|
| 再開ボタン | ▶ |
| 停止ボタン | ■ |

### 入力

| 入力 | 説明 |
|------|------|
| タイトル | 録音停止時に入力可能 |
| 音声 | MediaRecorder で AAC 44.1kHz 64kbps 録音 |

## 3. ImportReviewScreen（インポート完了画面）

### 概要
外部ファイルインポート直後の確認画面。再生・言語選択・文字起こし開始を行う。

### UI要素

| 要素 | 説明 |
|------|------|
| アイコン | 🎵 LibraryMusic |
| タイトル | 「インポート完了」 |
| ファイル名 | インポートしたファイル名 |
| 時間表示 | 音声の長さ（大文字） |
| 説明文 | 「音声を再生して内容を確認し、言語を選んで文字起こしを開始してください。」 |
| ▶ 再生ボタン | MediaPlayer で再生開始。再生中は「一時停止」に変化 |
| ⏹ 停止ボタン | 再生停止 |
| シークバー | Slider、ドラッグで早送り・巻き戻し |
| 🇯🇵 日本語ボタン | 日本語で文字起こし開始 |
| 🇨🇳 中国語ボタン | 中国語で文字起こし開始 |
| キャンセル | セッション削除＋ホームに戻る |

## 4. ProcessingScreen（文字起こし画面）

### 概要
文字起こし処理中の経過表示。進捗円グラフ、予測時間を表示。

### 状態遷移

```
IDLE → TRANSCRIBING → TRANSCRIBED → SUMMARIZING → COMPLETED
                         ↓             ↑
                        ERROR ← ← ← ← ←
```

#### TRANSCRIBING（文字起こし中）

| 要素 | 説明 |
|------|------|
| フェーズメッセージ | デコード中 / M4A分割中 / チャンクN送信中 |
| 経過時間 | カウントアップ表示 |
| 円グラフ | Canvas、分割(青)＋各チャンク(グラデーション)の割合表示 |
| 中央テキスト | 「分割」「Chunk1」「遅延」「準備」など状況に応じて変化 |
| 凡例 | 各色の意味表示 |
| 予測表示 | チャンク進捗(1/2)、予想残り時間、全体予測 |
| プログレスバー | LinearProgressIndicator |
| サービス表示 | 使用中のプロバイダ・モデル |
| keepScreenOn | 画面オフ防止 |

#### TRANSCRIBED（文字起こし完了）

| 要素 | 説明 |
|------|------|
| タイトル | 「文字起こし結果」＋処理時間 |
| テキスト編集エリア | OutlinedTextField、編集可能 |
| ▶ 再生 / ⏹ 停止 | 音声再生＋シークバー |
| リトライ | 文字起こしをやり直す |
| 戻る | 前画面に戻る |
| 保存(TXT) | DownloadフォルダにTXT保存 |
| 要約 | 要約設定ダイアログを開く |

### 要約設定ダイアログ

| 入力 | 説明 |
|------|------|
| 原文文字数 | 文字起こし結果の文字数（表示のみ） |
| 種類選択 | ExposedDropdownMenu：6種類から選択 |
| 最大文字数 | Slider（100単位、デフォルト=原文1/10） |

### SUMMARIZING（要約中）

| 要素 | 説明 |
|------|------|
| スピナー | CircularProgressIndicator |
| メッセージ | 「要約を生成中...」 |
| 経過/予想時間 | 「経過 12秒 / 予想 30秒」 |
| 使用モデル | 要約に使っているLLMモデル名 |

## 5. PreviewScreen（プレビュー画面）

### 概要
要約完了後の結果表示画面。文字起こし結果をWord書式で表示。

### UI要素

| 要素 | 説明 |
|------|------|
| ヘッダー | セッションタイトル、上部余白32dp |
| 言語チップ | 検出言語表示（AssistChip） |
| 🔍 縮小/拡大 | fontSizeSp 10-24sp 可変 |
| COPY | 全文クリップボードへコピー |
| ▶ 再生/■停止 | TTS音声読み上げ（Markdown記号除去済み） |
| 見出し | # → 大タイトル、## → 中見出し |
| 本文 | フォントサイズ可変、Markdown記号除去 |
| 受信者 | プルダウン選択＋手動入力 |
| メールで共有 | EmailShareService でメーラー起動 |
| 文字起こし結果 | SessionDetail画面へ遷移 |
| メニューへ戻る | ホームへ遷移（popUpTo HOME） |

---

## 6. SessionDetailScreen（セッション詳細画面）

### 概要
個別セッションの詳細表示。音声再生、文字起こし結果表示、メール共有。

### UI要素

#### 上部（情報カード）

| 項目 | 説明 |
|------|------|
| タイトル | セッション名（日付自動生成） |
| 日時 | 作成日時 |
| ステータス | 完了 / 共有済み など |
| モデル | LLMプロバイダ・モデル |
| 音声サイズ | KB表示 |
| 長さ | 録音時間 |
| 名前変更 | 名前変更ダイアログ（議題から自動生成） |

#### 音声再生

| 要素 | 説明 |
|------|------|
| ▶ ⏹ 再生/停止 | MediaPlayer |
| シークバー | Slider、ドラッグで早送り |

#### 文字起こし結果

| 要素 | 説明 |
|------|------|
| ヘッダー | 「保存」＋文字数＋処理時間 |
| 縮小/拡大 | フォントサイズ可変（lineHeight連動） |
| ▶ 再生/■停止 | TTS読み上げ（中文検出時は「日文」翻訳ボタン） |
| 本文 | Markdown記号除去＋段落ハイライト（TTS時） |

#### 下部

| 要素 | 説明 |
|------|------|
| 受信者 | プルダウン＋手動入力 |
| メールで共有 | メーラー起動（docx+md+txt添付） |
| 戻る | 前画面へ |
| 削除 | 確認ダイアログ→セッション削除 |

## 7. SettingsScreen（設定画面）

### サービス設定

| 項目 | 種類 | 説明 |
|------|------|------|
| API Key管理 | ボタン | APIKeyManagementScreenへ遷移 |
| サービス選択 | DropdownMenu | 6プロバイダから選択 |
| デフォルトモデル | DropdownMenu | プロバイダの対応モデル一覧 |

### 呼び出しモード

| 項目 | 種類 | 説明 |
|------|------|------|
| モード切替 | ボタングループ | MULTIMODAL / Whisper+要約 |
| オンデバイスWhisper | Switch | ONで端末内処理 |

### 文字起こし設定

| 項目 | 種類 | 説明 |
|------|------|------|
| AAC→WAVデコード | Switch | ON=高精度遅い、OFF=高速 |
| 分割サイズ | Slider | 1〜25MB |

### 要約テンプレート

| 項目 | 種類 | 説明 |
|------|------|------|
| 種別選択 | ボタングループ | 6種から選択 |
| テンプレート編集 | OutlinedTextField | 自由編集可能 |

### 読み上げ設定

| 項目 | 種類 | 説明 |
|------|------|------|
| エンジン選択 | DropdownMenu | システム標準+インストール済みエンジン |
| 話速 | Slider | 0.5〜2.0 |
| ピッチ | Slider | 0.5〜2.0 |
| 試聴 | ボタン | 設定でテスト音声再生 |

## 8. データモデル

### Session

| フィールド | 型 | 説明 |
|-----------|------|------|
| id | String | UUID |
| title | String | セッション名 |
| createdAt | Long | 作成日時(epoch ms) |
| durationMs | Long | 録音長さ(ms) |
| audioFilePath | String | 音声ファイルパス |
| audioSizeBytes | Long | 音声ファイルサイズ |
| status | SessionStatus | 状態 |
| transcriptMd | String? | 文字起こし結果(Markdown) |
| docxFilePath | String? | Wordファイルパス |
| mdFilePath | String? | MDファイルパス |
| txtFilePath | String? | TXTファイルパス |
| llmProvider | String? | 使用LLMプロバイダ |
| llmModel | String? | 使用モデル |
| processingDurationMs | Long | 処理時間(ms) |
